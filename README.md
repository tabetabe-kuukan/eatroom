# 食べ食べ空間

都市伝説の「検索ワード」を手がかりに AI が組み立てた、誰もいない 3D 空間を歩き、
残された痕跡から元になった都市伝説の名前を当てる WebGL ゲームです。全 6 空間。

## 人とAIの役割分担（課題スライド用）

この作品では、**人**がお題（都市伝説）と、それを連想させる「検索ワード」を区画ごとに設計しました。**AI**（Claude）はその検索ワードを受け取り、Blender の Python スクリプトで地形・建物・小物・照明を組み立て、Cycles でライトマップを焼き、three.js で歩ける空間に変換しました。**プレイヤー**は空間に残された痕跡から推理し、検索メモの単語を自分で検索して確かめます。答えはすべて Wikipedia に載っていますが、空間そのものは答えを語りません。お題を選ぶ人、言葉を空間にする AI、空間から言葉へ戻るプレイヤー。三者がそれぞれの役割を果たして、ひとつの体験が完成します。

## 遊び方

1. タイトル画面から「はじめから」。空間 1 から始まります。
2. 各空間には第1〜第3区画があり、奥に進むほど痕跡がはっきりします（第1区画: 雰囲気 / 第2区画: 関連する物 / 第3区画: 決定的な痕跡）。
3. 痕跡に近づくと、その検索ワードが「検索メモ」に記録されます。「この単語で検索する」で Google 検索が新しいタブで開きます。
4. 検索メモの回答欄に、元になった都市伝説の名前を入力します（ひらがな／カタカナ／空白／全角半角の違いは吸収します）。
5. 正解するとリザルト画面に Wikipedia の冒頭文が出て、次の空間へ進めます。進行状況はブラウザに保存され、「つづきから」で再開できます。

| 操作 | PC | スマホ |
|---|---|---|
| 移動 | WASD / 矢印キー | 画面左のバーチャルジョイスティック |
| 視点 | マウス（画面クリックでポインターロック） | 画面右側をドラッグ |
| 走る | Shift | ジョイスティックを端まで倒す |
| 検索メモ | Tab（または右上のボタン） | 右上のボタン |

## 起動・ビルド

Node.js 20 以上が必要です。

```bash
npm install
npm run dev        # 開発サーバー（http://localhost:5173）
npm run build      # Wikipedia の引用を取得してから dist/ に静的サイトを出力
npm run preview    # ビルド結果の確認
```

`dist/` の中身をそのまま静的ホスティング（GitHub Pages、Netlify など）に置けば動きます（相対パスでビルドしています）。

開発時は `http://localhost:5173/?space=3` のように番号を付けると、その空間を直接開けます。

### 3D モデルを作り直す（任意）

モデルはすべて `blender/` のスクリプトから再現できます。Blender 5.2 で確認しています。
Blender の場所は自動で探しますが、見つからない場合は環境変数 `BLENDER_PATH` で指定してください。

```bash
python blender/gen_textures.py                 # 看板・地図・新聞などの文字入りテクスチャ（Pillow）
node scripts/blender-build.mjs 01 02 03 04 05 06  # Blender をバックグラウンドで起動して生成・ベイク・書き出し
node scripts/optimize-models.mjs               # Draco 圧縮・WebP 化して public/ へ
node scripts/make-credits.mjs                  # CREDITS.md を更新
```

`--fast` を付けるとベイクのサンプル数を下げた確認用ビルドになります。
Cycles のプレビュー（WebGL 側との見比べ用）は `node scripts/blender-preview.mjs 02 out.png x y z yaw pitch` で出せます。

## 構成

```
blender/
  lib/kit.py           空間づくりの共通処理（素材・形・ライト・ライトマップ/AO のベイク・glTF 書き出し）
  lib/ph.py            Poly Haven（CC0）素材の取得とキャッシュ
  spaces/space0N_*.py  各空間の生成スクリプト
  gen_textures.py      文字入りテクスチャの生成
  space0N.blend        生成結果の .blend
  export/              書き出しの中間ファイル（メタデータ・素材の出典）
public/models/         最適化した .glb（Draco）とライトマップ（WebP）、空間のメタデータ
public/hdri/           環境光・反射用の HDRI
src/
  main.js              画面遷移・痕跡の判定・検索メモ・回答・リザルト
  engine/renderer.js   ACES トーンマッピング、ブルーム、ビネット、フィルムグレイン、色収差、自動解像度
  engine/world.js      空間の遅延読み込み（進捗表示）、ライトマップの適用、照明の揺らぎ
  engine/player.js     移動・視点・当たり判定・段差
  engine/audio.js      Web Audio による環境音の合成
  game/spaces.js       お題・検索ワード・正解の表記・雰囲気の設定（人が設計する部分）
  game/finale.js       最終空間の、プレイ記録から作る痕跡
  data/wiki.json       ビルド時に取得した Wikipedia の引用
```

## 技術メモ

- **ライティング**: 各空間の静的な形は 1 つのメッシュにまとめ、2 つ目の UV にライトマップ（Cycles の Diffuse 直接光＋間接光）と AO をベイクしています。AO は glTF の occlusion として、ライトマップは WebP の別ファイルとして読み込みます。草やシダなど細かい物は、照明を頂点カラーに焼いています。
- **質感**: Poly Haven の PBR テクスチャ（ベースカラー／ノーマル／ラフネス／AO）と、空間ごとの HDRI による環境光・反射を使っています。
- **圧縮**: メッシュは Draco、テクスチャは WebP（最大 1024px）。1 空間あたりの合計（glb＋ライトマップ＋HDRI）は次のとおりで、すべて 15MB 以下です。

| 空間 | 合計 |
|---|---|
| 1 ツチノコ | 11.8MB |
| 2 きさらぎ駅 | 6.6MB |
| 3 鮫島事件 | 6.2MB |
| 4 サンチアゴ航空513便事件 | 8.0MB |
| 5 メリーさんの電話 | 6.9MB |
| 6 お前 | 3.1MB |

- **フレームレート**: フレーム時間を見て描画解像度を 0.5〜1.5 倍の間で自動調整し、内蔵 GPU のノート PC でも 60fps を保つようにしています。スマホでは初期解像度とブルームの解像度を下げています。
- **音**: 環境音（蝉時雨、停車中の電車、遠くの太鼓と鈴、空調、電話のベルなど）はすべて Web Audio API で合成しています。

## 各空間の設計意図

| 空間 | お題 | 第1区画（雰囲気） | 第2区画（関連する物） | 第3区画（決定的な痕跡） |
|---|---|---|---|---|
| 1 | ツチノコ | 夏の山里の杉林の林道、苔むした石垣、草むら | 名前の剥がれた懸賞金の看板、木箱の罠、エサの一升瓶 | 胴の太い蛇の抜け殻、目撃地点に印を付けた地図 |
| 2 | きさらぎ駅 | 誰も乗っていない深夜の車内（0:24、本日の終電です） | 無人駅のホーム、遠くの太鼓と鈴、圏外の携帯電話 | かすれた駅名標、掲示板の画面の携帯、トンネルへ続く足跡 |
| 3 | 鮫島事件 | 深夜のネットカフェの個室（掲示板と書き込み画面） | 壁一面の「この投稿は削除されました」、黒塗りの報告書、「抹消」の印 | 空の段ボール箱の「事件資料」、削除だらけのスレッド、「この件には触れないこと」 |
| 4 | サンチアゴ航空513便事件 | 夜の空港ロビー、窓の外の滑走路とプロペラ機 | 1954年の出発案内板（513便 消息不明）、アーヘンのポスター、新聞 | 1989年ポルトアレグレのボーディングブリッジ、埃をかぶった機内、締めたままのシートベルト、乗客名簿 |
| 5 | メリーさんの電話 | 夜のゴミ捨て場、空の人形の箱、引っ越しの段ボール | 誰もいない駅前、受話器がぶら下がった公衆電話、西洋人形の落とし物 | アパートの廊下、だんだん近づく書き置き、部屋の中で鳴る電話（区画を越えるたびにも鳴る） |
| 6 | お前 | 空間1〜5で歩いた経路が、プールサイドの濡れた足跡になる | 入力した不正解の答えが壁に書かれている | 画面の方を向いた椅子と、何も映らない鏡 |

最終空間で正解すると、UI もカーソルも消えて画面全体が純粋な黒（#000000）になります。可能ならフルスクリーンにします。黒い画面に映り込んだプレイヤー自身の顔が「答え」です（カメラは使いません）。5 秒後に Wikipedia の引用を表示し、オールクリア画面へ進みます。

### 依頼内容から変えた点

- **空間4**: 「道路標識誘拐説」は日本語版 Wikipedia に単独の記事がなかったため、依頼者の指示で「サンチアゴ航空513便事件」に変更しました。実在の人物や死を直接描かない方針に従い、白骨そのものは描かず、空席に締められたままのシートベルトと埃で表しています（「白骨」は検索ワードとしてのみ使用）。
- **空間5**: 「メリーさん」の記事は実在の人物の記事だったため、「メリーさんの電話」の記事を使っています。
- **空間6**: 「お前」は「日本語の二人称代名詞」の記事に転送されるため、その記事の冒頭を引用しています。
- **参考画像**: 添付の 3 枚は `reference/` に、内容から空間番号を割り当てて置いています（暗い廊下 → 空間5、屋内プール → 空間6、座席の並ぶ客室 → 空間4）。
- **テクスチャ形式**: KTX2 ではなく WebP を使っています（依頼の「KTX2 または WebP」のうち、変換の手間とファイルサイズの釣り合いから選択）。
